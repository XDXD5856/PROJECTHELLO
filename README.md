# 35K · 飞行手账

**留一个靠窗的位置。**

一份给航空爱好者的小手账：把坐过的飞机、想飞的航线和窗外的回忆，收进一颗可旋转的地球。

![窗外的晨光](dist/assets/window.webp)

[在线打开 35K](https://thirty-five-k.groovy-tulip-4906.chatgpt.site) · 当前在线版本仅拥有者可访问。

## 打开就能用

下载这个分支的代码，直接用浏览器打开 **`dist/index.html`**。无需安装依赖、申请 API key 或注册账户。

也可以在项目目录运行：

```sh
python -m http.server 8080 --directory dist
```

然后打开 `http://localhost:8080`。Windows 可以把 `python` 换成 `py`。

## 可以做什么

- **航线地球**：拖动旋转、缩放，点击航线或列表定位。大圆弧自动处理跨日期变更线和背面遮挡。
- **登机牌详情**：航班、日期、机型、注册号、舱等、座位和最多 800 字的备注。
- **已飞 / 想飞**：用文字、实线 / 虚线与蓝 / 橙配色共同区分，不依赖红绿识别。
- **编辑与撤销**：创建、修改、删除；删除后 10 秒内可撤销。
- **统计与搜索**：已飞航班数、大圆距离、机场数、机型收藏；按状态筛选，按城市、代码、航司、机型、备注搜索。
- **数据备份**：JSON 完整备份、校验后合并导入、适合 Excel / Numbers 的 UTF-8 CSV。
- **76 个常用机场**：覆盖东亚、东南亚、欧美、澳新等。可在 `dist/data.js` 的 `AIRPORTS` 中扩展。
- **手机适配**：响应式单列界面、原生可访问对话框、键盘焦点提示、减少动态效果偏好支持。

## 你的数据

第一次打开是 **8 条虚构的示例航程**，用来体验界面。日期、航班号、机型与航线搭配只是演示，不能用于查询真实航班或订票。

点击「建立我的手账」后，从空白开始。个人记录与示例数据分开；示例编辑仅在本次打开有效。没有把任何真实个人行程写进源代码。

个人记录保存在**此设备、此浏览器、此网站地址**的 `localStorage`，不会自动上传 GitHub 或同步到另一设备。清理浏览器数据、使用隐私模式、改变站点域名或本地文件位置，可能使原记录不可用。换设备前请用「我的数据 → 下载 JSON 备份」，再在新设备导入。仓库里的代码备份不包含你的个人记录。

导入会先校验所有记录，失败时保留现有数据。同编号记录以备份为准，其余记录合并，最多 5,000 条，文件上限 8 MB。CSV 对常见公式起始字符做转义。若本地记录损坏，应用禁止覆盖，并提供原始 JSON 下载。

所有距离都是由机场坐标计算的**球面大圆距离估计**，不等于实际飞行轨迹里程或航空公司里程积分。统计仅计「已飞」；「待确认 / 其他」机型不计入机型收藏。

## 项目结构

```text
dist/
  index.html       页面和表单
  styles.css       响应式主题
  app.js           界面、地球、浏览器存储
  core.js          校验、导入合并、统计与 CSV
  data.js          机场、示例航班、地理轮廓
  assets/          本地依赖与窗外照片
tests/
  core.test.cjs    数据完整性与地理计算测试
package.json      零安装测试命令
THIRD_PARTY_NOTICES.md
```

不需要构建步骤。依赖已固定版本并放在 `dist/assets/`，运行时不从外部 CDN 请求资源。

如果安装了 Node.js 18 或更新版本，可运行：

```sh
npm test
```

## 扩展与托管

这是一个独立的静态项目，可以把 `dist/` 放到任何静态托管服务。`.openai/hosting.json` 只用于当前 Sites 版本，不是本地运行必需文件。将来若要多人使用或跨设备同步，需要另行实现账户和服务器存储；当前版本刻意保持为个人本地手账。

支持该提案的浏览器中，还会渐进注册两个 WebMCP 工具：`read_flight_journal` 读取当前记录；`start_flight_record` 打开填写界面而不自动保存。不支持 WebMCP 的浏览器不受影响。

## 保留或删除

这个实验在 `XDXD5856/PROJECTHELLO` 的 **`35k-flight-journal` 分支**，原 `main` 分支保留不变。删除这个分支即可移除 GitHub 上的实验版本；在线站点可在 Sites 中单独管理。删除代码或站点不会替你清除浏览器里的记录，清除站点数据前请先备份。
