# Projects

这里保存 PROJECTHELLO 目前已知项目的“项目卡”。

项目卡不是正式开发文档，也不替代独立仓库里的 README / AGENTS / STATUS。它的用途是让任何 AI 在接手前快速知道：

- 这个项目是什么；
- 为什么存在；
- 当前最重要的问题；
- 有哪些值得继续发展的想法；
- 下一步应该去哪里看。
